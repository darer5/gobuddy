# GoBuddy 客户端接口契约草案

## 1. 说明

本文档面向前端原型、WPF ViewModel、未来 WebView Bridge 或本地 IPC 层。它定义 UI 可以调用哪些应用能力，以及每个能力的输入、输出和事件。

MVP 阶段推荐直接用 C# 服务接口和 ViewModel 调用。若后续采用 WebView，可将这些契约映射为 `window.gobuddy.*`。

## 2. 统一响应

```ts
type ApiResult<T> = {
  ok: boolean;
  data?: T;
  error?: ApiError;
};

type ApiError = {
  code: string;
  message: string;
  details?: unknown;
};
```

## 3. Clipboard API

### clipboard.query

查询剪贴板历史。

```ts
type ClipboardQueryRequest = {
  keyword?: string;
  type?: "text" | "image" | "file" | "link";
  isFavorite?: boolean;
  limit: number;
  offset: number;
};
```

```ts
type ClipboardQueryResponse = {
  items: ClipboardItem[];
  total: number;
};
```

### clipboard.restore

将历史项恢复到系统剪贴板。

```ts
type ClipboardRestoreRequest = {
  id: string;
  mode: "copy_only" | "copy_and_paste";
};
```

### clipboard.delete

删除单条历史。

```ts
type ClipboardDeleteRequest = {
  id: string;
};
```

### clipboard.setFavorite

收藏或取消收藏。

```ts
type ClipboardSetFavoriteRequest = {
  id: string;
  isFavorite: boolean;
};
```

### clipboard.clear

清空历史。

```ts
type ClipboardClearRequest = {
  scope: "all" | "non_favorite" | "older_than_retention";
};
```

## 4. Screenshot API

### screenshot.startRegionCapture

进入区域截图模式。

```ts
type ScreenshotStartResponse = {
  sessionId: string;
  startedAt: string;
};
```

### screenshot.completeRegionCapture

完成区域截图。

```ts
type ScreenshotCompleteRequest = {
  sessionId: string;
  region: {
    monitorId: string;
    x: number;
    y: number;
    width: number;
    height: number;
    scaleFactor: number;
  };
};
```

```ts
type ScreenshotCompleteResponse = {
  screenshotId: string;
  filePath: string;
  width: number;
  height: number;
  copiedToClipboard: boolean;
  clipboardItemId?: string;
};
```

### screenshot.cancel

取消截图。

```ts
type ScreenshotCancelRequest = {
  sessionId: string;
};
```

## 5. Pet API

### pet.getState

获取宠物状态。

```ts
type PetState = {
  mood: "idle" | "happy" | "thinking" | "working" | "dragging" | "sleeping" | "alert";

  topMost: boolean;
  size: number;
  bubbleText?: string;
  position: {
    monitorId: string;
    x: number;
    y: number;
  };

```

### pet.dispatchAction

向宠物状态机发送动作。

```ts
type PetDispatchActionRequest = {
  action:
    | "click"
    | "hover"
    | "drag_start"
    | "drag_move"
    | "drag_end"
    | "clipboard_saved"
    | "screenshot_started"
    | "screenshot_done"
    | "ai_task_started"
    | "ai_task_completed"
    | "pause";
  payload?: unknown;
};
```

### pet.setPosition

保存宠物位置。

```ts
type PetSetPositionRequest = {
  monitorId: string;
  x: number;
  y: number;
};
```

## 8. Agent API

### agent.listProviders

```ts
type AgentProvider = {
  id: "codex" | "claude" | "custom" | string;
  displayName: string;
  executable: string;
  status: "not_installed" | "pending" | "connected" | "error";
  capabilities: string[];
  requiresApproval: boolean;
  lastProbeAt?: string;
  errorMessage?: string;
};
```

### agent.probeProvider

检测本地 CLI 是否可用。

```ts
type AgentProbeProviderRequest = {
  providerId: string;
};
```

```ts
type AgentProbeProviderResponse = {
  providerId: string;
  status: "not_installed" | "connected" | "error";
  version?: string;
  resolvedPath?: string;
  errorMessage?: string;
};
```

### agent.createTaskDraft

生成待确认任务草稿。MVP 可模拟返回。

```ts
type CreateAgentTaskRequest = {
  providerId: string;
  prompt: string;
  contextRefs: Array<{
    type: "clipboard_item" | "screenshot" | "workspace" | "manual_text";
    id?: string;
    value?: string;
  }>;
};
```

```ts
type AgentTaskDraft = {
  id: string;
  providerId: string;
  prompt: string;
  proposedCommand?: string;
  workingDirectory?: string;
  riskLevel: "L0" | "L1" | "L2" | "L3" | "L4";
  status: "draft" | "waiting_for_confirmation" | "denied";
  permissionPrompt: AgentPermissionPrompt;
};
```

### agent.cancelTask


## 9. 事件订阅

如果是 WPF ViewModel，可由内部事件总线订阅；如果是 WebView，可暴露：

```ts
window.gobuddy.events.subscribe(eventType, handler);
window.gobuddy.events.unsubscribe(eventType, handler);
```

事件类型：

```ts
type GoBuddyEvent =
  | { type: "clipboard.item_saved"; payload: { item: ClipboardItem } }
  | { type: "clipboard.item_restored"; payload: { id: string } }
  | { type: "screenshot.started"; payload: { sessionId: string } }
  | { type: "screenshot.completed"; payload: ScreenshotCompleteResponse }
  | { type: "pet.state_changed"; payload: PetState }
  | { type: "agent.provider_changed"; payload: AgentProvider }
  | { type: "agent.task_drafted"; payload: AgentTaskDraft }
  | { type: "agent.task_started"; payload: AgentTask }
  | { type: "agent.task_output"; payload: AgentTaskOutput }
  | { type: "agent.task_completed"; payload: AgentTask }
  | { type: "agent.task_failed"; payload: AgentTask };
```

## 10. 前端原型到接口映射

| 原型元素 | 未来接口 |
| --- | --- |
| 最近剪贴板列表 | `clipboard.query` |
| 搜索框 | `clipboard.query.keyword` |
| 类型筛选 | `clipboard.query.type` |
| 点击历史项 | `clipboard.restore` |
| 收藏星标 | `clipboard.setFavorite` |
| 清空 | `clipboard.clear` |
| 截图按钮 | `screenshot.startRegionCapture` |
| 截图区完成 | `screenshot.completeRegionCapture` |
| 宠物动作按钮 | `pet.dispatchAction` |
| 宠物位置变更 | `pet.setPosition` |
| AI Provider Tab | `agent.listProviders` / `agent.probeProvider` |
| AI Prompt | `agent.createTaskDraft` |
| 生成 CLI 任务 | `agent.createTaskDraft` |
| 后端待接入按钮 | 未来 `agent.startTask` |
| 设置弹层 | `settings.getAll` / `settings.update` |

## 11. MVP Mock 策略

为了让客户端开发逐步推进，建议先实现 Mock 服务：

- `MockClipboardService`：返回固定三条历史。
- `MockScreenshotService`：模拟截图开始和完成。
- `MockPetRuntime`：维护内存状态。
- `MockAgentBridge`：返回 Provider 和任务草稿，但禁止执行。
- `SQLiteStorageService`：可以先真实实现，因为它是低风险基础设施。

当真实系统能力接入时，以接口替换实现，不改 UI 调用方式。
